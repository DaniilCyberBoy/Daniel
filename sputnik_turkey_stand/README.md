# SPUTNIK — стенд в Турции (22 октября), оформление для печати

Стенд 3 × 3 м (9 м²), П-образный. Три стены, в каждой 3 панели **95 × 240 см**.
Печатается только внутренняя сторона (снаружи стенд закрыт соседями).
Стиль взят из файлов для Китая и Туниса: логотип, ленты, точки, QR-стиль и цвета скопированы из исходников Illustrator в векторе.

## Файлы для печати — `print/`

| Файл | Где стоит | Что на панели |
|---|---|---|
| `SPUTNIK_TR_L1…L3_95x240cm.pdf` | левая стена, изнутри, L1 у входа → L3 у задней стены | вертикальная лента с логотипами, QR-код, стрелка, плашка «BİZİ TAKİP EDİN» |
| `SPUTNIK_TR_C1…C3_95x240cm.pdf` | задняя стена, слева направо | большой логотип SPUTNIK |
| `SPUTNIK_TR_R1…R3_95x240cm.pdf` | правая стена, изнутри, R1 у задней стены → R3 у входа | слоган «Anlatılmayanları anlatıyoruz», вертикальная лента |
| `SPUTNIK_TR_Top_195x40cm.pdf` | верхняя табличка 195 × 40 см | SPUTNIK → Anlatılmayanları anlatıyoruz |

- Масштаб 1:1 (950 × 2400 мм и 1950 × 400 мм), CMYK, все тексты в кривых, растров нет. Файлы открываются и редактируются в Illustrator.
- Вылетов нет: формат как в файлах для Китая/Туниса. Если типография попросит вылеты, их легко добавить.
- Стойку ресепшен печатают организаторы (логотип им уже отправлен), её здесь нет.

Схема раскладки по панелям: `SPUTNIK_TR_Layout_A3.pdf`. Примерная визуализация: `SPUTNIK_TR_Preview.jpg`.

## Тексты

- **Anlatılmayanları anlatıyoruz** («говорим то, о чём другие молчат») — правая стена и верхняя табличка. Набран с заглавной первой буквой, как «Telling the untold» в прошлых макетах.
- **BİZİ TAKİP EDİN** («подписывайтесь на нас») — плашка у QR-кода, капсом, как «FOLLOW US ON SOCIAL MEDIA».
- Шрифт: Montserrat (поддерживает турецкие ı, İ). По пропорциям почти совпадает с шрифтом слогана в прошлых файлах.

## QR-код

Присланный PNG пересобран в вектор в том же стиле (точки, логотип в центре). Ссылка: `https://qrco.de/bh0UET`. Распознавание проверено на готовом файле.

## Допущение по конструкции

Между панелями стоят алюминиевые стойки, я принял их ширину за **5 см** (стандартный модуль 1 м). Рисунок стены рассчитан как сплошной, с учётом стоек: буквы, которые проходят через стык, совпадают по обе стороны. QR-код и плашка целиком лежат внутри своих панелей. Большой логотип и слоган неизбежно пересекают стыки.

`_build/` — скрипты, которыми собраны файлы (для правок: `REF_DIR=<папка с PDF Китай/Тунис> FONT=<Montserrat[wght].ttf> python3 _build/build.py out/`).
